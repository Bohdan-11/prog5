# Удалённый импорт модулей Python

Демонстрация механизма импорта Python-модулей не с локального диска,
а по HTTP/HTTPS-адресу.

## Состав

- `rootserver/myremotemodule.py` — модуль, который импортируется удалённо.
  Содержит функцию `myfoo()`, печатающую имя автора.
- `activation_script.py` — скрипт, реализующий удалённый импорт:
  - `URLLoader` — загрузчик: скачивает исходник модуля по URL,
    компилирует и выполняет его.
  - `URLFinder` — ищет модуль по имени в списке доступных на сервере
    `.py`-файлов и возвращает спецификацию для импорта.
  - `url_hook` — хук для `sys.path_hooks`: перехватывает пути вида
    `http://...` / `https://...`, скачивает HTML-листинг каталога
    и извлекает из него имена модулей.

## Как работает

1. `url_hook` добавляется в `sys.path_hooks`.
2. Когда URL попадает в `sys.path`, Python вызывает `url_hook`,
   который возвращает `URLFinder`.
3. `URLFinder.find_spec()` по имени модуля формирует URL вида
   `<url>/<name>.py` и возвращает спецификацию с `URLLoader`.
4. `URLLoader.exec_module()` скачивает исходник, компилирует
   и выполняет его в пространстве имён модуля.

## Запуск

1. Запустить HTTP-сервер в каталоге с модулем:
   bash
   cd rootserver
   python3 -m http.server

       В другом терминале запустить скрипт активации в интерактивном режиме:
    bash

    python3 -i activation_script.py

    В консоли Python:
    python

    >>> import myremotemodule          # ModuleNotFoundError — ожидаемо
    >>> sys.path.append("http://localhost:8000")
    >>> import myremotemodule
    >>> myremotemodule.myfoo()
    Лузан Богдан's module is imported

Ограничения базовой версии

    Хостинг должен отдавать HTML-листинг каталога (как http.server);
    иначе url_hook не найдёт имена модулей.

    Поддерживаются только плоские .py-модули (без пакетов).

    Нет обработки недоступности хоста и таймаутов.

    Используется urllib.request (без внешних зависимостей).
